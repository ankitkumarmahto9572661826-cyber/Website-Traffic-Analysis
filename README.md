# 📊 Sales Performance Analysis

## 📌 Project Overview

This project focuses on analyzing sales performance to identify sales trends,
top-performing products, customer patterns and important business insights.

## 🎯 Objective

The main objective of this project is to analyze sales data and create
meaningful visualizations and a dashboard to support data-driven business
decision-making.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Python
- Power BI
- Data Visualization
- Exploratory Data Analysis

## 📊 Project Analysis

The project includes:

- Sales performance analysis
- Product-wise sales analysis
- Sales trend analysis
- Category-wise performance
- Regional/segment analysis
- KPI analysis
- Dashboard visualization

## 📈 Dashboard

An interactive Sales Performance Dashboard was created to visualize
important sales KPIs and trends.
